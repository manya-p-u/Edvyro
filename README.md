# Edvyro


This repository contains my work completed as part of the **EdVyro Data Analytics Internship Program**.

## Tasks Completed

### Task 01 – Data Quality & Exploratory Analysis
- Audited and cleaned the customer churn dataset
- Handled missing values, duplicates, data types, and outliers
- Performed summary statistics
- Identified important patterns in the data

### Task 02 – Business KPI Dashboard
- Created an interactive customer churn dashboard
- Calculated key KPIs:
  - Churn Rate
  - Retention Rate
  - Revenue at Risk
  - Tenure
- Added filters and visualizations

### Task 03 – Segmentation & Recommendation Model
- Created customer segments based on customer behavior
- Developed a transparent rule-based churn-risk score
- Identified high-risk customer groups
- Provided customer retention recommendations

### Task 04 – Executive Analytics Capstone
- Summarized the major analytical findings
- Identified five important business insights
- Explained assumptions and limitations
- Provided three strategic recommendations
- Presented expected impact

## Tools Used

- Microsoft Excel
- Power BI
- Jupyter Notebook
- Python / Pandas
- GitHub

## Overall Workflow

**Data → Cleaning → EDA → KPIs → Dashboard → Segmentation → Recommendations → Executive Report**
